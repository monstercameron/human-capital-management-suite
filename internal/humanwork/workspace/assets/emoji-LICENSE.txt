Emoji data for the Chat emoji picker
=====================================

These files (emoji-order.json and emoji-<language>.json) are generated by tools/emojidata
from Unicode's emoji data and the Unicode CLDR annotations. Do not edit them by hand:
place the source files in .artifacts/unicode/ and run

    go run ./tools/emojidata -in .artifacts/unicode -out internal/humanwork/workspace/assets
